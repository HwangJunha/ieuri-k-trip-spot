다이렉트 메시지 화면과 재진입 경로

Stitch가 이 스펙의 DM 화면을 끝내 생성하지 못해(피드 화면은 생성됨), 앱의 디자인 시스템 토큰을 그대로 써서 직접 그린 목업이다. 색·타입·간격 값은 모두 DESIGN.md에서 가져왔다 — 구현할 때는 이 페이지의 값이 아니라 Theme.of(context)에서 읽는다.

재진입 경로가 이 문서의 핵심이다. 피드 항목의 DM 아이콘은 새 대화를 여는 입구일 뿐이라, 그것만으로는 이미 나눈 대화로 돌아갈 길이 없다 — 대화를 시작한 피드가 스크롤로 지나가거나 삭제되면 접근이 끊긴다. 그래서 둘러보기 탭 헤더에 메시지 아이콘을 둔다.

1재진입점 — 둘러보기 헤더

메시지 아이콘은 토글과 같은 헤더 영역에 둔다. 제스처 표면(스와이프 카드·세로 스크롤) 위에 겹치지 않으므로 드래그와 경합하지 않는다. 하단 탭은 이미 5개로 꽉 차 있고, DM은 피드에서만 생기는 기능이라 피드가 있는 탭의 헤더가 맥락상 맞는 자리다.

2대화 화면

말풍선은 ownedByViewer로 정렬이 갈린다(발신 primary, 수신 surface — DESIGN.md §6). 텍스트 전용이며 수정·삭제 UI는 없다. 위로 스크롤하면 과거를 더 불러온다.

3두 진입 경로

둘 다 같은 ConversationScreen에 도착한다. 라우트에는 conversationId만 넘긴다.

새 대화   피드 항목의 DM 아이콘 ──startConversation──▶ ConversationScreen
재진입    헤더의 메시지 아이콘 ──▶ ConversationListScreen ──탭──▶ ConversationScreen
